# Projektart Spiel

Für Spiele jeder Art. `/projekt-anlegen` liest diese Datei: die Werte unten, die Bereiche aus der Tabelle. Ein Bereich mit einer Frage in der Spalte „Nur wenn“ kommt nur dazu, wenn der Nutzer sie mit Ja beantwortet.

- **Nutzerbegriff:** Spieler
- **Assets-Spalte:** ja

## Bereiche

| Bereich | Farbe | Wofür | Nur wenn |
|---|---|---|---|
| Gameplay | GREEN | Spielregeln, Spiellogik, Balance | |
| Oberfläche | BLUE | Menüs, HUD, Eingabe, Ansichten | |
| Grafik | ORANGE | Bilder, Sprites, Animationen | |
| Audio | ORANGE | Musik, Soundeffekte | |
| Inhalte | RED | Level, Texte, Daten (Gegenstände, Gegner) | |
| Technik | GRAY | Engine, Build, Plattformen, Werkzeuge | |
| Server | PURPLE | Backend, Konten, Online-Funktionen | Hat dein Spiel einen Online-Teil? |
