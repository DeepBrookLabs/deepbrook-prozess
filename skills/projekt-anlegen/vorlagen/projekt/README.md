## Mitarbeiten

Dieses Projekt arbeitet spec-getrieben mit Claude Code nach dem Prozess aus [DeepBrookLabs/deepbrook-prozess](https://github.com/DeepBrookLabs/deepbrook-prozess):

1. `/spec-idee` hält eine Idee als Spec-Issue fest.
2. `/spec #<nr>` grillt die Idee zu einer Spec in [docs/specs/](docs/specs/) und schneidet sie in Tickets.
3. Die Tickets wandern über das Kanban-Board und werden per PR umgesetzt.

Skills wiederherstellen nach dem Klonen: `npx skills experimental_install`.
